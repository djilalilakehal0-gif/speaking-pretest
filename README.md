# Speaking Pre-Test — Alfikr Almodi School

تطبيق أندرويد لاختبار التحدّث بالإنجليزية. يعمل بدون إنترنت أثناء الاختبار، ويمكن لأي عدد من الطلاب استعماله في نفس الوقت.

---

## أولاً: تجهيز المستودع على GitHub (مرة واحدة فقط)

1. **ارفع كل محتوى هذا المجلد** إلى المستودع، واستبدل الملفات القديمة. يجب أن تشمل المجلدين `assets` و `.github` (المجلد `.github` مخفي على الماك؛ اضغط `Cmd + Shift + .` لإظهاره).
2. **اجعل المستودع عامّاً (Public)** حتى يستطيع الطلاب التحميل بدون حساب:
   Settings → General → أسفل الصفحة → Change visibility → Public.
3. **أضف مفتاح التوقيع (سرّان)**:
   Settings → Secrets and variables → Actions → **New repository secret**
   - الاسم: `KEYSTORE_BASE64` ← الصق النص الطويل من ملف `مفاتيح-التوقيع.txt`
   - الاسم: `KEYSTORE_PASSWORD` ← الصق كلمة السر من نفس الملف

   هذا المفتاح يجعل كل نسخة جديدة تُثبَّت فوق القديمة على هواتف الطلاب بدون حذف. **احتفظ بملف `مفاتيح-التوقيع.txt` في مكان آمن، ولا ترفعه إلى GitHub.**

4. اذهب إلى **Actions** ← **Build Android APK** ← **Run workflow**. انتظر حوالي 5 دقائق حتى تظهر علامة ✅.

## ثانياً: رابط التحميل للطلاب

بعد نجاح البناء، يُنشر التطبيق تلقائياً في **Releases**، ويكون رابط التحميل الثابت:

```
https://github.com/اسم-المستخدم/اسم-المستودع/releases/latest/download/SpeakingPreTest.apk
```

مثال: `https://github.com/djilalilakehal0-gif/speaking-pretest/releases/latest/download/SpeakingPreTest.apk`

- الرابط لا يتغيّر أبداً، ويعطي دائماً آخر نسخة.
- حوّله إلى **رمز QR** (مثلاً من موقع qr-code-generator.com) واطبعه أو أرسله في واتساب.

## ثالثاً: خطوات التثبيت للطالب

1. يمسح رمز QR أو يفتح الرابط، فيبدأ تحميل الملف `SpeakingPreTest.apk`.
2. يفتح الملف من الإشعارات أو من «التنزيلات».
3. إذا ظهرت رسالة «غير مسموح بتثبيت تطبيقات من هذا المصدر»: يضغط **الإعدادات** ويفعّل **السماح من هذا المصدر**، ثم يرجع.
4. يضغط **تثبيت**. إذا ظهر تحذير Play Protect: **تفاصيل إضافية** ← **التثبيت على أي حال**.
5. يفتح التطبيق مرة واحدة ويسمح بـ **الميكروفون**.

> **مهم:** يكون التحميل قبل يوم الاختبار، وليس في القاعة. الملف لا يحتاج إنترنت، ويمكن نقله بين الهواتف عبر **المشاركة السريعة (Quick Share)** أو البلوتوث.

## رابعاً: يوم الاختبار

- لا يحتاج إنترنت.
- يجب أن تكون **ساعة كل هاتف مضبوطة على «الوقت التلقائي»**، لأن رمز البدء يُحسب من الوقت.
- المعلّم: يفتح «المعلّم» ← كلمة السر ← يقرأ الرمز للطلاب. الرمز نفسه على كل الهواتف ويتغيّر كل 10 دقائق.
- يُستحسن تقسيم الطلاب على صفوف (25–30 طالباً) واستعمال سماعات بميكروفون لتقليل الضجيج.

## تغيير كلمة سر المعلّم

في الملف `www/index.html` ابحث عن:

```js
const TEACHER_PASSWORD='2027';
const CODE_SECRET='alfikr-almodi-speaking-pretest';
```

غيّر القيمتين قبل البناء. بعد أي تعديل، ارفع الملف إلى GitHub فيُبنى ويُنشر تلقائياً. يكفي أن يفتح الطلاب نفس الرابط ويثبّتوا من جديد، فتتحدّث النسخة **بدون حذف الإجابات**.

> ملاحظة: بما أن المستودع عام، فكلمة السر تكون مكشوفة لمن يقرأ الكود. هذا مقبول لاختبار تمهيدي. إذا أردت حماية أقوى، يجب إضافة خادم.

## محتوى المجلد

| الملف | الوظيفة |
|---|---|
| `www/index.html` | التطبيق كله (الأسئلة، التسجيل، وضع المعلّم) |
| `www/img/` | صور الأسئلة والمهام والشعار |
| `www/audio/` | الصوت النسائي المسجّل (16 جملة)، يعمل بدون إنترنت |
| `www/fonts/` | خط IBM Plex داخل التطبيق، يعمل بدون إنترنت |
| `assets/` | أيقونة التطبيق وشاشة البداية (من شعار المدرسة) |
| `capacitor.config.json` | اسم التطبيق ومعرّفه `com.djilali.speakingpretest` |
| `package.json` | مكتبات Capacitor 7 (ميكروفون، ملفات، مشاركة، نطق احتياطي) |
| `.github/workflows/build-apk.yml` | يبني ملف APK موقّعاً وينشره في Releases تلقائياً |
