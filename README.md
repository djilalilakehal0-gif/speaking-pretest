# Speaking Pre-Test — Alfikr Almodi School

تطبيق أندرويد وآيفون لاختبار التحدّث بالإنجليزية. يعمل بدون إنترنت أثناء الاختبار، ويمكن لأي عدد من الطلاب استعماله في نفس الوقت.

---

## أولاً: تجهيز المستودع على GitHub (مرة واحدة فقط)

1. **ارفع كل محتوى هذا المجلد** إلى المستودع، واستبدل الملفات القديمة. يجب أن تشمل المجلدين `assets` و `.github` (المجلد `.github` مخفي على الماك؛ اضغط `Cmd + Shift + .` لإظهاره).
2. **اجعل المستودع عامّاً (Public)** حتى يستطيع الطلاب التحميل بدون حساب:
   Settings → General → أسفل الصفحة → Change visibility → Public.
3. **أضف كلمة سر مفتاح التوقيع**:
   Settings → Secrets and variables → Actions → **New repository secret**
   - الاسم: `KEYSTORE_PASSWORD` ← الصق كلمة السر (20 حرفاً، بدون مسافات)

   المفتاح نفسه يُقرأ من السرّ `KEYSTORE_BASE64` إن وُجد، وإلا من الملف `KEYSTORE_BASE64.txt` في المستودع. هذا المفتاح يجعل كل نسخة جديدة تُثبَّت فوق القديمة على هواتف الطلاب بدون حذف. **لا تغيّر المفتاح بعد توزيع التطبيق**، وإلا سيضطر الطلاب لحذف التطبيق القديم.

4. اذهب إلى **Actions** ← **Build Android APK** ← **Run workflow**. انتظر حوالي 5 دقائق حتى تظهر علامة ✅.

## ثانياً: رابط التحميل للطلاب

بعد نجاح البناء، يُنشر التطبيق تلقائياً في **Releases**، ويكون رابط التحميل الثابت:

```
https://github.com/اسم-المستخدم/اسم-المستودع/releases/latest/download/SpeakingPreTest.apk
```

مثال: `https://github.com/djilalilakehal0-gif/speaking-pretest/releases/latest/download/SpeakingPreTest.apk`

- الرابط لا يتغيّر أبداً، ويعطي دائماً آخر نسخة.
- حوّله إلى **رمز QR** (مثلاً من موقع qr-code-generator.com) واطبعه أو أرسله في واتساب.

## ثالثاً: خطوات التثبيت للطالب

1. يمسح رمز QR أو يفتح الرابط، فيبدأ تحميل الملف `SpeakingPreTest.apk`.
2. يفتح الملف من الإشعارات أو من «التنزيلات».
3. إذا ظهرت رسالة «غير مسموح بتثبيت تطبيقات من هذا المصدر»: يضغط **الإعدادات** ويفعّل **السماح من هذا المصدر**، ثم يرجع.
4. يضغط **تثبيت**. إذا ظهر تحذير Play Protect: **تفاصيل إضافية** ← **التثبيت على أي حال**.
5. يفتح التطبيق مرة واحدة ويسمح بـ **الميكروفون**.

> **مهم:** يكون التحميل قبل يوم الاختبار، وليس في القاعة. الملف لا يحتاج إنترنت، ويمكن نقله بين الهواتف عبر **المشاركة السريعة (Quick Share)** أو البلوتوث.

## رابعاً: يوم الاختبار

- لا يحتاج إنترنت.
- يجب أن تكون **ساعة كل هاتف مضبوطة على «الوقت التلقائي»**، لأن رمز البدء يُحسب من الوقت.
- المعلّم: يفتح «المعلّم» ← كلمة السر ← يقرأ الرمز للطلاب. الرمز نفسه على كل الهواتف ويتغيّر كل 10 دقائق.
- يُستحسن تقسيم الطلاب على صفوف (25–30 طالباً) واستعمال سماعات بميكروفون لتقليل الضجيج.

## نسخة الويب: أسهل طريقة للآيفون

تُنشر نسخة ويب من التطبيق تلقائياً مع كل رفع إلى `main`، على الرابط:

```
https://djilalilakehal0-gif.github.io/speaking-pretest/
```

**التفعيل (مرة واحدة):** Settings → Pages → في **Source** اختر **GitHub Actions**. ثم Actions → **Publish web version** → Run workflow.

**على الآيفون:** افتح الرابط في **Safari** ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. يظهر التطبيق بأيقونة المدرسة، ولا يحتاج كمبيوتر ولا حساب آبل. عند أول تسجيل اضغط **سماح** للميكروفون.

الإجابات تُحفظ داخل Safari، لذلك يجب **مشاركتها** (واتساب مثلاً) بعد الاختبار، وعدم مسح بيانات Safari قبل ذلك.

## خامساً: نسخة الآيفون (iOS)

تُبنى نسخة الآيفون تلقائياً على GitHub (على جهاز ماك تابع لـ GitHub)، فلا تحتاج ماك ولا Xcode. بعد كل رفع إلى `main`، أو من **Actions** ← **Build iOS app** ← **Run workflow**، يظهر الملف في **Releases** تحت الإصدار `ios-3.N`.

آبل لا تسمح بتثبيت ملف التطبيق مباشرة كما في أندرويد، فهناك طريقتان:

**أ) بدون حساب مطوّر (مجاناً، للتجربة أو لعدد قليل من الأجهزة)**
1. حمّل الملف `SpeakingPreTest-unsigned.ipa` من Releases.
2. على كمبيوتر (ويندوز أو ماك) ثبّت برنامج **Sideloadly** (أو AltStore)، ووصّل الآيفون بالكابل.
3. اسحب الملف إلى البرنامج، وادخل بحساب Apple ID عادي، واضغط Start.
4. على الآيفون: الإعدادات ← عام ← VPN وإدارة الجهاز ← اختر حسابك ← **وثوق**. ومن iOS 16: فعّل **وضع المطوّر** من الإعدادات ← الخصوصية والأمان.
5. حدود الحساب المجاني: التطبيق يعمل **7 أيام** ثم يجب إعادة تثبيته، وبحد أقصى 3 تطبيقات لكل جهاز.

**ب) بحساب Apple Developer (99 دولاراً في السنة، للتوزيع على الطلاب)**
1. من developer.apple.com: سجّل المعرّف `com.djilali.speakingpretest`، وأنشئ شهادة **Apple Distribution**، ثم ملف تعريف (Provisioning Profile) من نوع **Ad Hoc** (لأجهزة مسجّلة بأرقامها UDID، حتى 100 جهاز) أو **App Store** (للنشر عبر TestFlight).
2. صدّر الشهادة بصيغة `.p12` بكلمة سر، وحوّل الملفين إلى نص Base64 (`base64 -i cert.p12`).
3. أضف ثلاثة أسرار في Settings → Secrets and variables → Actions:
   - `IOS_CERT_P12_BASE64` ← نص الشهادة
   - `IOS_CERT_PASSWORD` ← كلمة سر الشهادة
   - `IOS_PROFILE_BASE64` ← نص ملف التعريف
4. شغّل البناء من جديد، فيظهر الملف الموقّع `SpeakingPreTest.ipa`. ملف Ad Hoc يُثبَّت على الأجهزة المسجّلة، وملف App Store يُرفع إلى TestFlight ببرنامج **Transporter** على الماك.

على الآيفون:
- يطلب التطبيق إذن **الميكروفون** في أول تسجيل؛ يجب الضغط على «سماح».
- الإجابات المحفوظة تظهر في تطبيق **الملفات** ← «على الـ iPhone» ← Speaking Pre-Test.
- يحتاج iOS 14.5 أو أحدث.

## تغيير كلمة سر المعلّم

في الملف `www/index.html` ابحث عن:

```js
const TEACHER_PASSWORD='2027';
const CODE_SECRET='alfikr-almodi-speaking-pretest';
```

غيّر القيمتين قبل البناء. بعد أي تعديل، ارفع الملف إلى GitHub فيُبنى ويُنشر تلقائياً. يكفي أن يفتح الطلاب نفس الرابط ويثبّتوا من جديد، فتتحدّث النسخة **بدون حذف الإجابات**.

> ملاحظة: بما أن المستودع عام، فكلمة السر تكون مكشوفة لمن يقرأ الكود. هذا مقبول لاختبار تمهيدي. إذا أردت حماية أقوى، يجب إضافة خادم.

## محتوى المجلد

| الملف | الوظيفة |
|---|---|
| `www/index.html` | التطبيق كله (الأسئلة، التسجيل، وضع المعلّم) |
| `www/img/` | صور الأسئلة والمهام والشعار |
| `www/audio/` | الصوت النسائي المسجّل (16 جملة)، يعمل بدون إنترنت |
| `www/fonts/` | خط IBM Plex داخل التطبيق، يعمل بدون إنترنت |
| `assets/` | أيقونة التطبيق وشاشة البداية (من شعار المدرسة) |
| `capacitor.config.json` | اسم التطبيق ومعرّفه `com.djilali.speakingpretest` |
| `package.json` | مكتبات Capacitor 7 (ميكروفون، ملفات، مشاركة، نطق احتياطي) |
| `.github/workflows/build-apk.yml` | يبني ملف APK موقّعاً وينشره في Releases تلقائياً |
| `.github/workflows/deploy-web.yml` | ينشر نسخة الويب على GitHub Pages (رابط للآيفون) |
| `.github/workflows/build-ios.yml` | يبني ملف IPA للآيفون (موقّعاً إذا أُضيفت أسرار آبل) وينشره في Releases |
