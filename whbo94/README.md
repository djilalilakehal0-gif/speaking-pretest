# نور اليقين — whbo94

منصة مقاطع الدعاء واليقين بالله: React + Tailwind CSS 4 + Framer Motion للواجهة، وخادم Node (Express) مع قاعدة بيانات SQLite حقيقية للمحتوى والمصادقة.

## التشغيل محلياً
```bash
npm install
ADMIN_PASSWORD='كلمة-مرور-قوية' npm run dev   # الواجهة :5173 والخادم :3000
```
للإنتاج: `npm run build && ADMIN_PASSWORD=... npm start` ثم افتح `http://localhost:3000`.

## الإدارة
- الرابط: `/admin`. يُنشأ حساب المسؤول عند أول تشغيل من `ADMIN_USER` (الافتراضي `admin`) و`ADMIN_PASSWORD`؛ إن لم تُحدَّد تُولَّد كلمة مرور عشوائية وتُطبع في الطرفية مرة واحدة.
- من اللوحة: إضافة/تعديل/حذف المقاطع، رفع الغلاف والفيديو (MP4/WebM) أو إدخال رابط (يوتيوب أو ملف مباشر)، التصنيف، الترتيب، تثبيت مقطع مميز، قراءة رسائل «اتصل بنا»، وتغيير كلمة المرور.
- كلمات المرور مُشفّرة بـ scrypt، والجلسات في كوكي `HttpOnly` مع محدّد معدّل لمحاولات الدخول.

## المحتوى
لا توجد مقاطع وهمية: المكتبة فارغة حتى تضيف مقاطعك، وتظهر رسالة واضحة للزائر. صورة الواجهة الرئيسية: `public/hero.jpg` (استبدلها بصورتك).

## الإعدادات
| المتغير | الوصف |
|---|---|
| `PORT` | المنفذ (3000) |
| `DATA_DIR` | مجلد قاعدة البيانات والمرفوعات (`./data`) |
| `ADMIN_USER` / `ADMIN_PASSWORD` | حساب المسؤول الأول |
| `TRUST_PROXY` | اضبطه خلف وكيل عكسي (HTTPS) |

## النشر
`docker build -t whbo94 . && docker run -p 3000:3000 -v w94data:/data -e ADMIN_PASSWORD=... whbo94` — احفظ `/data` في وحدة تخزين دائمة. يتطلب Node 22.13+ (يستخدم `node:sqlite`).

الاختبارات: `npm test`.
